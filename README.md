# SSHnesh

SSH-клиент с SFTP для Windows, Linux и Android. На Windows и Linux встроенный MCP подключает Codex к SSHnesh; устанавливать Node.js для этого не нужно.

## Запуск

- **Windows:** распакуйте ZIP и запустите `sshnesh-preview.exe`. В локальной папке проекта актуальная сборка уже распакована в `dist/tauri-preview/native-win-x64`, куда указывает ярлык SSHnesh.
- **Linux:** установите пакет DEB и запустите SSHnesh.
- **Android:** установите APK для ARM64. SSH и SFTP доступны, MCP — только в настольной версии.

В карточке сервера откройте **Учётки**, чтобы настроить профиль для диагностики. Если нужен Codex, нажмите **MCP → Скопировать команду для Codex** и выполните её один раз. После этого можно попросить Codex посмотреть состояние службы на сохранённом или текущем сервере. MCP включён по умолчанию; его можно выключить в меню MCP.
